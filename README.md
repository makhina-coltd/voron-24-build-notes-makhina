# Voron 2.4 組立ノート（株式会社MAKHINAによる非公式資料）

株式会社MAKHINAが Voron 2.4 R2（LDO製キット Rev D+、300mm）を組み立てた経験をもとに作成した、組立マニュアルの日本語改訂版と部品表です。

**本資料は Voron Design の公式資料ではなく、Voron Design の承認・サポートを受けたものでもありません。**
公式の情報は次を参照してください。

- Voron Documentation：https://docs.vorondesign.com/
- VoronDesign/Voron-2（設計データと公式マニュアル）：https://github.com/VoronDesign/Voron-2

## 原本からの主な変更点

- 英語から日本語に翻訳した
- わかりにくい箇所に説明を追記した。追記した箇所には「MAKHINA注」と明記している
- Voron Design のロゴを削除した（図中に写り込んだものを含む）
- 改訂ごとの変更内容と日付は `CHANGELOG.md` に記録している

## 部品表について

- 株式会社MAKHINAが購入したキットの現物をもとに作成した（購入元：Sugoi3D、購入時期：2026-09-21）
- 「Rev D+」はLDO製キットの版の呼び方で、Voron Design の版（R2）とは別のものである
- 「推定」と記した項目は現物からの推測で、未確認である
- キットの内容は版やロットによって変わる可能性がある。購入前に販売店に確認すること

## 改訂の方針

本資料の改訂は、次の方針で行う。

1. 原本の図はそのまま残し、追記は「MAKHINA注」として原本の内容と区別できるようにする。ただし、図中に写り込んだ Voron Design のロゴは消す
2. 原本の内容を修正・削除した場合は、原本のページ番号とあわせて `CHANGELOG.md` に記録する
3. Voron Design のロゴは使用しない
4. PDFの表紙または奥付に、非公式資料であること、原本の版、改訂日、GPL-3.0で提供することを明記する
5. 取り込むのは GPL-3.0 で公開されている資料に限る。販売店の資料やライセンス表記のない資料は写さず、リンクで示す
6. 根拠のない数値や推測は、「根拠なし」「推定」と明記する
